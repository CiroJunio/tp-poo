# Campanha Simulada

Este projeto simula batalhas entre exércitos utilizando diferentes tipos de unidades (infantaria, veículos, aeronaves). O sistema permite simular uma série de batalhas, gerar tabelas de posições e identificar as unidades mais destrutivas.

## Estrutura do Projeto

- `src/`: Contém os arquivos de implementação.
- `include/`: Contém os arquivos de cabeçalho.
- `Makefile`: Arquivo de construção utilizando `make`.
- `README.md`: Este arquivo.

## Compilação
